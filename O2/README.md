### O2 Scratch Card

A functional demonstration using SwiftUI simulating a scratch card featuring 3 main screens:

1. **ContentView** – shows the card's current state and acts as entry point to the two other views
2. **ScratchView** – reveals a randomly generated UUID code
3. **ActivateView** – sends the code with GET request and checks the result

### Requirements
- macos 27+
- Xcode 27+
- Simulator iOS 27+
